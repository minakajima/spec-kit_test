```
前提条件: ゲーム開始、プレイヤーヘルス=3

1. 敵出現 → 敵弾発射開始
2. プレイヤー移動 → 敵弾接触
3. 衝突判定発動 → ダメージ処理
4. ヘルス減少 → 無敵時間開始
```
